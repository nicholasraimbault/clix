# Clix v0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two Arch boxes become one owner: pair with a phrase, `clix add adb` on the laptop, `clix laptop adb` from the server, no login, visible job, wait if the lid is down.

**Architecture:** One Rust binary (`clix`). `clix daemon` is the sidecar (systemd --user). The CLI talks to the local daemon over a Unix socket (owner: add/allow/pair). Paired daemons talk over the tailnet (exec/request only). Tests run two daemons on localhost with fake transport so we do not need two machines until the Tailscale task.

**Tech Stack:** Rust 2021, clap 4, tokio, serde_json, thiserror, directories, which, spake2, ed25519-dalek, notify-rust, ksni (tray), nix. Transport: Unix socket locally, HTTP/JSON on the Tailscale IP for mesh.

## Global Constraints

- Two Arch Linux machines. No Andrix in v0.
- Native shells stay native. No Clix shell you enter.
- `clix <body> <cmd>` is honest location. No silent routing.
- Hands are added on that box, by you. The agent cannot grant itself tools on another machine.
- Mesh may `exec` and `request` only. `add` / `remove` / `allow` / `deny` / `pair` are local-owner Unix socket only.
- Exec is `execve` of the granted binary. No `/bin/sh -c`. No PTY. No leftover session.
- `clix add adb` with no flags: every paired body, until `clix remove adb`.
- `--allow <body>` / `--server`, `--once`, `--for`, `--until`, `--weekdays` only narrow a grant.
- `--until` and `--weekdays` use am/pm (9am, 5pm), not 24-hour clocks.
- `--once` does not stack with `--weekdays`.
- Denied exec becomes a request. Approve via native OS notification or `clix allow`. Never in the agent chat.
- Default allow is `--once` unless the owner widens it.
- Sleep: block and print `laptop is asleep, waiting…`. Never surface `connection refused` as the user-facing error.
- Pin `~/src` both ways. If both sides wrote, stop and say so. No invented merge.
- Tailscale is plumbing. Clix identity is not a Tailscale account.
- No compositor, no new VPN, no guest distro. Request UI is native notifications plus an optional tray.
- Owner can work with no agent. Same commands for you and the agent.
- Errors in Clix language (`adb is not added on laptop`, `laptop is asleep, waiting…`), never raw SSH/TCP strings.
